SprintLab Track

User Guide

Publisher: Vytera Labs Ltd  ·  For: SprintLab Track on 15 Garmin watches  ·  info@vyteralabs.com

SprintLab Track times the reps a Run or Track Run profile cannot, runs the rest, and saves an ordinary FIT activity that reaches Garmin Connect the same way every other run on that watch does.

If you read nothing else
  • One button contract everywhere: START is always the forward action, and BACK never drops you out of a session by accident.
  • Both buttons stop a running rep. A rep stopped by the “wrong” button is still a rep.
  • Rep times come from the lap boundary, not from what the screen was showing — press at the line.
  • Version 1 ships Manual timing. Leave the timing mode on Manual until the other modes are released.

1. The five screens

The whole app is five screens deep, and the button that moves you forward is always the same one.

ScreenWhat it shows
HomeThe session you are about to run, a one-line summary of your last one, and START.
ReadyWhat is coming — set, rep and distance — and one button to start it.
RepThe elapsed time, and deliberately nothing else. No heart rate, no rep counter, no distance.
RestThe countdown, what you just ran against your session best, and what is next.
SummaryEvery rep with its drop-off and heart-rate recovery, the session verdict, then save or discard.

2. The session library

Six sessions, chosen with UP and DOWN on the Home screen so the start button is never more than one press away.

SessionShape
6 × 60m / 3'Six reps, three minutes' rest.
4 × 150m / 6'Four reps, six minutes' rest.
3 × 300m / 10'Three reps, ten minutes' rest.
2 × (3 × 200m)Two sets of three, four minutes between reps and twelve between sets.
Speed endurance 120–150–180Three reps at three distances, walk-back recovery — you control the rest, so the rest clock counts up rather than down.
CustomYour own sets, reps, distance, rest and set rest. Remembered between sessions.

3. Running a session

StepWhat to do
1Open SprintLab Track. On Home, press UP or DOWN to pick the session.
2Press START. The Ready screen shows the rep you are about to run.
3On the line, press START to begin the rep. The clock runs.
4At the end of the rep, press START or BACK/LAP — either stops it. The rest clock begins.
5Walk back. When you are ready early, press START to end the rest and arm the next rep. That does not start the rep clock — you still have to walk to the line.
6After the last rep, the Summary appears. Page it with UP and DOWN, rate the session, then save or discard.

4. The buttons

One contract, fixed across every screen, so it can be learned once and used with cold hands.

ButtonAction
START / ENTERThe forward action: start the rep, stop the rep, end the rest, save.
BACK / LAPStops the rep while one is running. Otherwise, steps back.
UP / DOWNChange the selection, or page the summary.
MENUSettings — from Home only.
BACK is consumed everywhere inside a session. A stray press mid-set must never drop you out of the app and bin the recording, so leaving a session is always an explicit confirmation. Both buttons stop a running rep on purpose: a sprinter reaching for the watch at the line hits whichever is under the thumb, and a rep stopped by the "wrong" button is still a rep.

6. What lands in Garmin Connect

SprintLab Track records through the watch's own activity recording, so it produces an ordinary FIT activity that syncs over the same path as a native run. The app uploads nothing itself and has no network code at all.

  • An activity in your timeline, titled SprintLab Track and typed as a track run, with duration, calories, average and max heart rate, and the heart-rate graph.
  • A continuous heart-rate trace. The session records through the rests as well as the reps, so there are no gaps between efforts.
  • One lap per rep and one lap per rest. Rep times are readable from the lap duration column alone — which matters, because that is the one place the data must survive even if Connect renders none of the custom fields.

7. If a rep time looks wrong

Rep duration is taken at the lap boundary, which is precise to the instant you pressed the button. What the watch displays during a rep updates about once a second; the recorded time does not depend on that. If a rep is short by roughly the time you spent reaching for the watch, that is the rep you ran — press at the line, not after it.
