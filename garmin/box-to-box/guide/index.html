Box to Box

User Guide

Publisher: Vytera Labs Ltd  ·  For: Box to Box on 71 Garmin watches  ·  info@vyteralabs.com

Box to Box records football training sessions, small-sided games and 5-a-side. It measures sprints, high-intensity distance, accelerations and decelerations, and saves a native Football activity that reaches Garmin Connect the same way every other activity on that watch does.

If you read nothing else
  • Wait for GPS ok on the start screen before pressing START.
  • START pauses for a stoppage. LAP (the BACK button) ends the period.
  • Screen taps and swipe-back do nothing during a session, so a tackle cannot stop it. To finish, use the menu.
  • If you record no sprints, the default of 25 km/h may be too fast for your group. Lower it in the settings on your phone.

1. The screens

ScreenWhat it shows
StartYour session plan (for example 2 × 45 min), GPS status, and START.
ClockPeriod and plan at the top, the period clock large, then total elapsed time and heart rate.
RunningCurrent speed at the top, distance large, then max speed and sprint count.
IntensityHigh-intensity share at the top, high-intensity distance large, then accelerations and decelerations.
SummaryAfter saving: session totals, heart rate, time in each HR zone, then one page per period.

The line at the foot of each data page shows GPS status and the page number, or PAUSED, AUTO PAUSE or BREAK when the session is not running. A heart rate the watch cannot read is shown as a dash.

2. Running a session

StepWhat to do
1Open Box to Box outdoors. Wait for GPS ok.
2Press START. The first period begins and recording starts.
3When the drill stops, press START to pause. Press it again to resume; the period carries on.
4At full time the watch buzzes and the clock turns amber, counting added time. Press LAP when the period really ends.
5Between periods the screen shows BREAK. Press START to begin the next period. The break counts towards neither period.
6After the last period, the menu offers Save, Add extra time and Discard. Save shows the summary.

Extra time: choose Add extra time from the menu, then 5, 10 or 15 minutes. It becomes the next period. Finishing early: choose Finish session from the menu; any unplayed periods are dropped.

Last session: on the start screen, open the menu and choose Last session to see your previous summary again.

3. The buttons

ButtonAction
START / STOPStart the session, pause for a stoppage, resume, start the next period. After the last period, opens the save menu.
BACK / LAPWhile running: ends the period. While paused, on a break or finished: opens the menu. On the start screen: leaves the app.
UP / DOWN, or swipeChange data page, or page through the summary.
MENU (hold UP)The session menu: resume, end period, add extra time, finish, save, discard.
Touchscreen watches. On a Venu or vívoactive, the top button is START and the bottom button is BACK/LAP. Taps and swipe-right are ignored during a session, so a knock cannot pause it, end a period or close the app. Every action can be reached with the two buttons alone: LAP opens the menu whenever the session is paused.

Speed thresholds are always entered in km/h, the unit sports science publishes them in. Units changes only what the screens show. Auto-pause pauses after 10 seconds standing still and resumes when you move again; it is off by default because standing is normal in drills.

5. How the metrics are measured

  • Distance adds up GPS speed, second by second, so high-intensity distance is always part of total distance.
  • A sprint starts when speed reaches the sprint threshold and counts once it has lasted the minimum duration. It ends only when speed falls clearly below the line, so one run is never counted twice.
  • High-intensity distance is the distance covered at or above the high-intensity speed.
  • An acceleration counts the first time speed rises faster than the threshold, and a deceleration the first time it falls faster. Each effort counts once.
  • GPS spikes are capped at a change no human can make (8 m/s²), and a capped reading can never start an effort.
The honest limit. Watches receive GPS once a second; professional vests record ten times a second. Bursts shorter than a second cannot be seen at one fix a second, so accelerations and decelerations read lower than a vest's, and very short peaks read a little slow. Box to Box deliberately applies no smoothing beyond the spike cap, because smoothing would hide the one-second efforts football is made of. Compare your sessions with each other on the same watch.

6. What lands in Garmin Connect

  • A Football activity in your timeline, typed as football (soccer), so Garmin Connect, Strava and Training Load treat it correctly. It includes your GPS track, heart rate, calories and time in zones.
  • One lap per period. Half-time is excluded.
  • The football metrics for the whole session: B2B distance, B2B max speed, sprints, high-intensity distance, accelerations, decelerations, GPS fix rate, GPS mode and number of periods.
  • The same metrics per period, in the lap view.

The app uploads nothing itself and has no network code at all.

7. If a number looks wrong

What you seeWhy, and what to do
0 sprints25 km/h held for a second is quick for recreational players. Lower the sprint speed to 20–22 km/h.
Distance looks shortStart only after GPS ok. Tight turns cut corners at one fix a second; expect a few per cent under a vest.
Different from Garmin's own distanceGarmin filters its distance differently. Both figures are in the activity, each labelled.
Heart rate lags or jumpsWrist sensors struggle in stop-start play. Pair a chest strap; Box to Box uses it automatically.

8. Supported watches

Every watch on Connect IQ System 7 (API 5.0) or later that has GPS: 71 models.

Older watches — Forerunner 245 and 945, fēnix 6, the first Venu and others below System 7 — cannot install paid Connect IQ apps, so they are not offered Box to Box. Edge cycling computers and handheld GPS units are excluded because they are not worn during play.
