Sprint Start

User Guide

Publisher: Vytera Labs Ltd  ·  For: Sprint Start on Forerunner 265 and 265S  ·  info@vyteralabs.com

Sprint Start runs the four commands of a track start, holds each one for a length you cannot predict, and times the run from the instant the Go tone fires.

If you read nothing else
  • The holds are random to the millisecond, and no countdown is shown during a random stage — that is the whole point of the app.
  • The clock starts on the Go tone, so your time includes your reaction to the sound you actually heard.
  • If it vibrates but does not beep, it is the watch’s Sound & Vibe settings, not the app. Section 5 has the fix.
  • No GPS, no network, no account, nothing recorded.

1. The sequence

Four commands. The two in the middle are held for a length you cannot predict.

StageCueDuration
Get Ready1 beep + 1 buzzFixed, 10s by default — optionally random
On Your Marks1 beep + 1 buzzRandom, 4–10s by default
Set2 beeps + 2 buzzesRandom, 3–7s by default
Go1 beep + 1 buzzStopwatch starts, and runs until you stop it

Set is two beeps rather than one on purpose: it is the one command an athlete must never mistake for another, and a doubled cue is distinguishable at the far end of a track when a single one is not.

The stopwatch zero is taken at the instant the Go cue is issued, so the time includes your reaction to the sound you actually heard.

2. Running a start

Open Sprint Start from the watch's app list. The idle screen shows the ranges it is currently set to.

StepWhat to do
1Press START/STOP (top right). Get Ready begins, with a countdown if that stage is fixed.
2Walk up on the On Your Marks cue, and settle. The screen turns amber. No countdown is shown.
3Come up on the double cue for Set. The screen turns red.
4Go on the single beep. The stopwatch is already running from that instant.
5Press START/STOP at the line to stop the clock. Press BACK to reset for the next rep.

3. The buttons

ButtonAction
START/STOP (top right)Idle: begin the sequence. Running: stop the stopwatch. Mid-sequence: abort.
BACK (bottom right)Reset. Pressed again with nothing to reset, it closes the app.
Hold UPOpen settings.
BACK only exits once the screen is already clear. A stray press during a session resets the timer instead of dropping you out of the app mid-rep.

4. Settings

Every value is a whole number of seconds, 0–60. Change them on the watch by holding UP, or from your phone — Garmin Connect → your device → Connect IQ Apps → Sprint Start → Settings. Both routes edit the same stored values.

SettingDefaultWhat it does
Randomise Get ReadyOffDraw the walk-up time at random instead of using a fixed length.
Get Ready / Get Ready min10Walk-up time — the lower bound when randomised.
Get Ready max10Upper bound, used only when randomised.
Marks min / Marks max4 / 10The On Your Marks hold range.
Set min / Set max3 / 7The Set hold range.

If you raise a minimum above its maximum, the maximum is raised to match rather than leaving an impossible range.

5. If it vibrates but does not beep

This is almost always the watch's own sound settings rather than the app: Settings → System → Sound & Vibe. The Beeps toggle in Sprint Start cannot override them.

The usual trap is that tones are enabled only during an activity. Sprint Start is a plain watch app — it never starts a timed activity, so the watch does not consider you to be in one while it runs, and tones scoped that way never fire. Vibration is often not scoped the same way, which is exactly why you can get one without the other. Enable tones for the non-activity case as well.

Failing that, check that alerts are not set to vibration-only. To confirm it is the watch and not the app, leave Sprint Start: if a button press or an incoming notification is also silent, the watch is muting everything.

6. Starting a group

The cues are audible to anyone standing near the watch, so the same app starts a squad as easily as it starts one athlete. Put the watch down at the blocks, press START, and get behind it.
