Sprint Start

Support

Publisher: Vytera Labs Ltd  ·  Updated: 18 September 2026  ·  info@vyteralabs.com

Sprint Start is a sprint start simulator: it runs the four commands of a track start, holds each one for a length the athlete cannot predict, and times the run to a thousandth of a second. Everything it does, it does on the watch.

Before you write in
  • The user guide covers the controls, every setting with its default, and the problems that actually come up.
  • Sprint Start is not yet on the Connect IQ Store. If you are running it, you sideloaded it, and some Garmin Connect features — phone-side settings among them — are not available to sideloaded apps.

Getting help

Write to info@vyteralabs.com. It is a small studio, not a support desk: you will get a reply from the person who wrote the app, usually within a few working days.

What to include

Four things turn a report we cannot place into one we can fix:

  • Your watch model, and the software version it is running — on the watch, Settings → System → About.
  • What you did, step by step, and what happened instead of what you expected.
  • Whether it happens every time, or only sometimes.
  • How you installed it — from the Connect IQ Store, or sideloaded.

Common questions

It vibrates but does not beep.

This is almost always the watch’s own sound settings rather than the app — Settings → System → Sound & Vibe. The usual trap is that tones are enabled only during an activity; Sprint Start is a plain watch app and never starts one, so tones scoped that way never fire. Enable tones for the non-activity case as well. The user guide covers this in full.

Can I get it on my watch?

It is built for the Forerunner 265 and 265S today. Other watches can be added — tell us which model you have.

Can I change how long the holds are?

Yes. Every stage is adjustable between 0 and 60 seconds, on the watch by holding UP or from Garmin Connect. See Settings in the guide.

Does it work without my phone?

Entirely. It never needs a phone, a network or an account.

Feature and device requests

Both are welcome at the same address. If you want a watch supported that is not on the list, say which model you have — that is the single most useful thing you can tell us, and the list grows that way.
